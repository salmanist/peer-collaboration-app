# How We'll Work — Salman & Zahra

## Repo
- Salman will upload the project to GitHub.
- `main` branch = the base, working version of the app.

## Steps

1. **Build the base module first.** "User Authentication and Profiles" is built and put on `main` before anything else. Salman will build it, and you both will work on it.

2. **Make two git branches from `main`:**
   - `salman`
   - `zahra`

3. **Each of us builds our own modules on our own branch.** Salman works only on the `salman` branch, Zahra works only on the `zahra` branch. Each module connects to User Profiles, but not to each other's modules. Use the command "git push origin zahra" instead of "git push origin main". Make a .gitignore file and for ignoring files and mention in them files that arent yours or shared for commiting to github safely.

4. **We keep working on our branches until we are both fully done** with all our modules. We do not merge early, one module at a time.

5. **When both of us are done, we merge both branches into `main`.**

6. **After merging, we test everything together** — all modules, running as one app — and fix any problems we find.

## Simple Rules

- Don't edit the other person's files/folders.
- If both of us need the same shared thing (like login checks or notifications), talk about it first before adding it.
- Save your work often on your own branch — it only needs to work fully at the end, not every day.
